# 自分の開発コンテキストを作る

Python 3.10以上だけで動く対話式セットアップです。追加インストールやAPIキーは不要です。

```sh
python3 setup_context.py --output ../my-ai-context
```

15問に自由文で答えると、価値観・理由・UI/UXの具体例・開発の完了基準・AIへの委任範囲をMarkdownにまとめます。所要時間は回答の長さによります。途中で `:quit` と入力して保存し、同じコマンドで再編集できます。空Enterは既存回答を維持、`:clear` はその回答を削除します。Ctrl+Cや入力終了でも、ここまでの回答を保存します。

回答をAIが分析するツールではありません。本人の言葉をそのまま整理し、未回答は未決定として残します。生成された文書を読んでから使ってください。矛盾の整理や追加の質問は、生成文書を使ってAIと相談できます。

GitHubへは、確認後に専用の非公開リポジトリへ登録できます。Git操作や外部送信は行いません。各AIへの接続・参照設定は別途必要です。出力にあるAGENTS.mdやCLAUDE.mdを置くだけで、ChatGPTやClaudeの通常チャットに自動適用されるものではありません。

生成ファイルに手動編集があれば、上書きせず止まります。別の出力先へ生成して比較してください。出力フォルダには回答を保存した `.context-state.json` も含まれます。

価値観の文書化はコンテキスト整備、これを毎回の参照・作業・検証・更新につなげる仕組みはハーネスの一部、と考えて設計しています。
